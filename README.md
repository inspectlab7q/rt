# 陸上クラブ 保護者LINEグループBot

小学生陸上クラブの保護者LINEグループで使うBotです。
これまでトーク履歴で行っていた出欠確認を、**ボタンで回答できる形**にします。
回答は **Googleカレンダー・スプレッドシート・Googleドライブ** と連携して記録されます。

サーバー代はかかりません。Google Apps Script（無料）の上で動きます。

## できること

| 機能 | 内容 |
|---|---|
| 📅 予定の自動案内 | 係の人がGoogleカレンダーに練習・大会を入れると、7日前に出欠ボタン付きのカードをグループに自動で流します |
| ✅ ボタンで出欠 | 「出席／欠席／未定」を押すだけで回答できます。きょうだいがいる家庭は、誰の回答かを選べます |
| ⏰ 未回答リマインド | 2日前に、出欠一覧と未回答の子をグループに流します |
| 🔄 変更・中止のお知らせ | 案内済みの予定をカレンダーで変更・削除すると、自動でお知らせします |
| 📷 写真の自動保存 | グループに送った写真を、Googleドライブの「大会・練習ごとのフォルダ」に自動で保存します |
| 🏃 レース結果の記録 | 「結果 100m 15.2秒」と送ると、スプレッドシートに記録が残ります |
| 📊 データはスプレッドシートに | 出欠・記録・写真の一覧は、役員がスプレッドシートで見たり編集したりできます |

## グループでの使い方（保護者向け）

| 送る言葉 | 何が起きるか |
|---|---|
| `登録 山田たろう` | お子さんの名前を登録します（最初に1回だけ）。きょうだいは `登録 山田たろう 山田はなこ` |
| `予定` | これからの予定が出欠ボタン付きで表示されます |
| `出欠` | 直近7日の予定の出欠一覧と未回答者が表示されます |
| `結果 100m 15.2秒` | レース結果を記録します。きょうだいがいる場合は `結果 はなこ 走り幅跳び 3m20` のように名前から書きます。記録のあとに書いた言葉はメモになります |
| `記録` | お子さんの記録一覧が表示されます |
| `写真` | 写真フォルダのリンクが表示されます |
| `ヘルプ` | 使い方が表示されます |

普段の会話には反応しません。Botが反応するのは、メッセージの最初の言葉が上のコマンドと完全に一致したときだけです。
たとえば「予定は？」「結果どうだった？」には反応しません。

## しくみ

```
Googleカレンダー ──(毎朝同期)──▶ Apps Script ◀──(Webhook)── LINEグループ
                                  │
                ┌─────────────────┼─────────────────┐
                ▼                 ▼                 ▼
         スプレッドシート     Googleドライブ      LINEへ返信・通知
       (家族/予定/出欠/結果/写真)  (写真フォルダ)
```

スプレッドシートには次のシートができます。

- **家族**：LINEユーザーとお子さんの名前の対応
- **予定**：カレンダーから取り込んだ予定（案内済み・リマインド済みの状態も入ります）
- **出欠**：予定ごと・お子さんごとの回答
- **結果**：レース結果（手入力で追加してもかまいません）
- **写真**：保存した写真の一覧とリンク

## セットアップ（役員・係の方向け、30分ほど）

### 1. LINE公式アカウントとMessaging APIを用意する

1. [LINE Developers](https://developers.line.biz/) にLINEアカウントでログインします
2. プロバイダーを作成し、**Messaging APIチャネル**を作成します。チャネルを作ると、LINE公式アカウントも同時にできます
3. 「Messaging API設定」タブで、**チャネルアクセストークン（長期）**を発行してメモします
4. [LINE Official Account Manager](https://manager.line.biz/) の「設定 > アカウント設定」で、**「グループ・複数人チャットへの参加を許可する」をオン**にします
5. 「応答設定」で、**応答メッセージをオフ**、**Webhookをオン**にします

### 2. Googleカレンダーを用意する

1. Googleカレンダーで、クラブ用のカレンダー（例：「陸上クラブ」）を新しく作ります
2. 「設定と共有 > カレンダーの統合」にある**カレンダーID**をメモします
3. 予定を入れる係の人に、「予定の変更権限」で共有します
4. 保護者にもカレンダーを共有しておくと、各自のスマホのカレンダーアプリでも予定が見られます

### 3. Apps Scriptにコードを入れる

**方法A：ブラウザでコピー＆ペースト（かんたん）**

1. [script.google.com](https://script.google.com/) で「新しいプロジェクト」を作ります
2. `src/` にある `.gs` ファイルを、同じ名前のファイルとして作ってすべて貼り付けます
3. 「プロジェクトの設定」で「appsscript.json マニフェストファイルをエディタで表示する」をオンにし、`src/appsscript.json` の内容を貼り付けます

**方法B：clasp を使う（開発者向け）**

```sh
npm install -g @google/clasp
clasp login
clasp create --type standalone --title "陸上クラブBot" --rootDir src
clasp push
```

### 4. スクリプト プロパティを設定して setup を実行する

1. 「プロジェクトの設定 > スクリプト プロパティ」に次の2つを追加します
   - `LINE_CHANNEL_ACCESS_TOKEN`：手順1でメモしたトークン
   - `CALENDAR_ID`：手順2でメモしたカレンダーID
2. エディタで関数 `setup` を選んで「実行」します。初回は権限の許可を求められるので、許可してください
3. 実行ログに、スプレッドシートと写真フォルダのURLが表示されます。どちらも自分のGoogleドライブに作られます

### 5. Webアプリとして公開し、LINEにWebhook URLを登録する

1. 「デプロイ > 新しいデプロイ > 種類：ウェブアプリ」を選びます
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
2. 表示されたウェブアプリのURLの末尾に、`?token=` とスクリプト プロパティ `WEBHOOK_TOKEN` の値を付けます
   - 例：`https://script.google.com/macros/s/xxxx/exec?token=abcd1234...`
3. LINE Developersの「Messaging API設定 > Webhook URL」にこのURLを登録し、「Webhookの利用」をオンにします
   - 「検証」ボタンはエラーになることがあります（Apps Scriptはリダイレクトで応答するためです）。実際のメッセージは届くので、気にしなくて大丈夫です

> コードを更新したときは、「デプロイを管理 > 編集 > バージョン：新バージョン」で同じデプロイを更新してください。新しいデプロイを作るとURLが変わってしまいます。

### 6. グループに招待する

1. 保護者のLINEグループに、作った公式アカウントを招待します
2. Botがあいさつを返したら完了です。グループIDは自動で保存されます
3. 保護者のみなさんに、`登録 お子さんの名前` を送ってもらいます

これで準備完了です。翌朝7時から、カレンダーの予定が自動で案内されるようになります。
すぐに試したいときは、グループで `予定` と送ってください。予定は `setup` を実行した時点で取り込まれています。

## 設定の変更

`src/Config.gs` の `CONFIG` で、次の項目を変えられます。

- 何日前に案内するか（`ANNOUNCE_DAYS_AHEAD`）
- 何日前にリマインドするか（`REMIND_DAYS_BEFORE`。0にするとリマインドしません）
- 毎朝の処理を何時に動かすか（`DAILY_HOUR`。変更したら `setup` をもう一度実行します）
- 写真を自動保存するか（`SAVE_ALL_PHOTOS`）
- 出欠ボタンを押したときに確認の返信をするか（`CONFIRM_ATTENDANCE`）

## 注意点

- **メッセージ通数**：Botの返信（コマンドやボタンへの応答）は無料で、何回でも送れます。いっぽう、毎朝の自動案内・リマインド・お知らせは「プッシュメッセージ」なので、LINE公式アカウントの無料枠（月200通）を使います。グループへのプッシュは**グループの人数分**として数えられるので、人数が多いグループでは無料枠をすぐ使い切る可能性があります。足りないときは、次のどれかで対応してください。最新の料金はLINE公式アカウントの料金ページで確認してください
  - `REMIND_DAYS_BEFORE` を 0 にして、リマインドを止める
  - 自動案内は使わず、保護者が `予定` と送って確認する運用にする（返信なので無料です）
  - 有料プランにする
- **個人情報**：スプレッドシートと写真フォルダは、`setup` を実行した人のGoogleドライブに作られます。共有するのは役員や保護者の必要な人だけにして、「リンクを知っている全員」での公開は避けてください
- **写真**：グループに送られた写真はすべて保存されます。保存したくない場合は `SAVE_ALL_PHOTOS` を `false` にしてください。動画は保存しません
- **セキュリティ**：Apps Scriptでは、LINEの署名ヘッダーを検証できません。その代わりに、Webhook URLの `token` で不正なリクエストを弾いています。Webhook URLは他の人に教えないでください
